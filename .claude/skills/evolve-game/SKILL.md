## Фаза 0 — Аудит и проектирование (ultrathink)

Перед любым кодом — прочитай `CLAUDE.md` и весь `scripts/`. Затем создай или полностью обнови `ROADMAP.md` в корне проекта. Документ должен содержать:

### ROADMAP.md структура

**1. Core Loop (математически выраженный):**
```
Действие → Немедленная Награда → Накопление → Вызов → Действие
Пример: Убил врага (300$) → Купил SMG → Убил 3 врагов быстрее → Зона сжалась → Паника → Решение
```
Опиши формулу роста сложности: `difficulty(round) = base * (1 + round * 0.15)^2`
Опиши кривую вознаграждения: как меняются деньги/XP за раунд 1, 5, 10, 20.

**2. Типы врагов (минимум 5), каждый с:**
- Уникальным поведением (стейт-машина: Патрулирование → Преследование → Атака → Отступление)
- Математикой: HP, урон, скорость, дальность агро, reward
- Визуальным отличием (цвет/форма в _draw())
- Контр-стратегией игрока (чем его бить)

Пример минимального набора:
- `Grunt` — прямолинейный, слабый, роится
- `Rusher` — быстрый, хрупкий, игнорирует препятствия
- `Sniper` — стоит, стреляет издали, убегает при сближении
- `Tank` — медленный, огромный HP, толкает баррикады
- `Bomber` — бежит к игроку, взрывается при смерти

**3. Система перков (минимум 8):**
Открываются за XP между раундами. Каждый перк — конкретная цифра:
- `Tough` — +25 макс HP
- `Scavenger` — ресурсы с врагов +50%
- `Quick Hands` — скорость постройки ×2
- `Zone Runner` — урон от зоны -40%
- `Headhunter` — убийство даёт +$150 бонус
- `Arsenal` — начальные патроны +60
- `Steel Nerves` — хит-стоп при получении урона 0.05s вместо 0.12s
- `Last Stand` — при HP < 20 скорость +30%

**4. Стейт-машина игры:**
```
MainMenu → [Play] → RoundStart (freeze 5s + buy phase)
         → Playing → [Died / Last Alive] → RoundEnd
         → UpgradeScreen (выбор 1 из 3 перков) → RoundStart
         → [Round 10 или последний враг] → VictoryScreen
         
VictoryScreen / DeathScreen → показать статистику:
  Раунд, Убийств, Урона нанесено, Построено стен, Время, Лучшая серия
```

## Фаза 2 — Враги и боёвка (параллельные субагенты)

Запусти **два субагента параллельно**:

**Субагент A — Враги и спавнер:**
- `enemy_ai.gd`: базовый класс с стейт-машиной (IDLE→CHASE→ATTACK→FLEE)
- 5 типов врагов наследуют базовый класс, переопределяют только параметры и `_decide_state()`
- `enemy_spawner.gd`: волны врагов, `spawn_wave(round: int)` → количество и типы по формуле
- Патфайндинг: A* через `AStar2D` или упрощённый steering (normalize(target - pos))
- Рендер врагов в `world_renderer.gd` (_draw, отличающиеся фигуры)

**Субагент B — Стрельба и физика снарядов:**
- `projectile.gd`: снаряд (позиция, скорость, урон, TTL), движется в _process
- `combat_system.gd`: `shoot(origin, direction, weapon_id)` → создаёт Projectile
- Хитдетекция: круговые коллизии между Projectile и Enemy/Player позициями
- Кнопка стрельбы в hud.gd: правый нижний угол, большая, отдельная от крафта/закупки
- Авто-прицел на ближайшего врага в радиусе 300px (мобильная QoL фича)

После завершения субагентов — объединить, запустить тесты.

## Фаза 4 — Прогрессия и GameLoop

`round_manager.gd` реализует полный цикл:
1. `start_round(n)` — спавнит `n * 3 + 5` врагов волнами, открывает магазин на 10s
2. `_on_all_enemies_dead()` → показать `upgrade_screen.gd` (3 случайных перка на выбор)
3. `_on_perk_chosen(id)` → применить перк к `player_state`, начать следующий раунд
4. `_on_player_died()` → показать `game_over_screen.gd` со статистикой
5. После 10 раундов → победный экран

Сохранение рекорда: `ConfigFile` в `user://highscore.cfg`.
